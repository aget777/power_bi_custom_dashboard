# Spec for Рекламная активность - Топ 5 Розница

figma_component (if used): not used

## Summary
Добавить на страницу `Рекламная активность` правый верхний аналитический блок `ТОП-5 • РОЗНИЦА`: таблицу Top 5 брендов по розничной рекламной активности с логотипами, горизонтальными барами, SOV справа от бара и нижним блоком `ПРОДУКТОВЫЕ СЕГМЕНТЫ`.

## Functional Requirements

### Data Sources
- Бренды: `brand_main_Top[brand_main_top]`.
- Логотипы: `logos_dict[logo_link]`.
- Значение для ранжирования, подписи и бара: мера `3122_01_TPR_Розница`.
- Значение в строках отображается в целых числах с фиксированной подписью `TRP`.
- Процент в заголовке в скобках: мера `3122_02_SOV_%_Розница`, формат `0% АКТИВНОСТИ`.
- Значение `% SOV` в строках справа от бара: мера `3121_02_SOV_%_category_5_n_6`, формат `0% SOV`.
- Блок `ПРОДУКТОВЫЕ СЕГМЕНТЫ`:
  - `Дебетовые карты`: `3123_02_SOV_%_Розница_Дебетовые_карты`;
  - `Сберегательные продукты`: `3124_02_SOV_%_Розница_Сбер_продукты`;
  - `Реферальная программа`: `3125_02_SOV_%_Розница_Реф_программа`.
- Названия продуктовых сегментов отображаются внутри цветных блоков в uppercase:
  - `ДЕБЕТОВЫЕ КАРТЫ`;
  - `СБЕРЕГАТЕЛЬНЫЕ ПРОДУКТЫ`;
  - `РЕФЕРАЛЬНАЯ ПРОГРАММА`.

### Ranking Logic
- Показывать не более пяти брендов.
- Исключать blank/0 по `3122_01_TPR_Розница`.
- Исключать `ОСТАЛЬНОЕ`.
- Сортировать по `3122_01_TPR_Розница` по убыванию, при равенстве по названию бренда по возрастанию.
- Учитывать текущий filter context страницы через `ALLSELECTED('brand_main_Top'[brand_main_top])`.

### Layout
- Реализация: единый HTML visual.
- HTML-мера: `_Меры_30_Presentation[3202_02_html_top5_retail]`.
- Visual container: `aa100000000000000008`.
- Позиция на странице `5752fcd0093969ea3e03`:
  - `x=782.4900766593191`;
  - `y=221.40582904726915`;
  - `w=715.1604212588783`;
  - `h=305.0`.

### Visual Style
- Стиль аналогичен таблице `ТОП-5 • ОБЩАЯ РЕКЛАМА`.
- Акцент розничного блока: мятный `#63D7BE`.
- Цвета продуктовых сегментов по референсу:
  - `Дебетовые карты`: `#63D7BE`;
  - `Сберегательные продукты`: `#E2C16F`;
  - `Реферальная программа`: `#EF6B78`.
- Каждый продуктовый сегмент имеет цветную рамку, вертикальный маркер слева, название слева и процент справа.
- Фон карточки: `#0F1722`.
- Рамка: `#1C2739`.
- Основной текст: `#E3EAF2`.
- Вторичный текст: `#9AA3B2`.
- Visual header, background и border контейнера выключены.

## Acceptance Criteria
- На странице есть блок `ТОП-5 • РОЗНИЦА`.
- В заголовке отображается процент из `3122_02_SOV_%_Розница` в скобках со словом `АКТИВНОСТИ`.
- Таблица показывает Top 5 брендов с логотипом, названием, значением, баром и `% SOV`.
- Значение и ширина бара рассчитываются по `3122_01_TPR_Розница`.
- Значение отображается в формате `#,0 TRP`.
- `% SOV` справа от бара рассчитывается по `3121_02_SOV_%_category_5_n_6`.
- Нижний блок `ПРОДУКТОВЫЕ СЕГМЕНТЫ` показывает три значения из мер `3123_02`, `3124_02`, `3125_02`.
- Визуал не перекрывает существующие блоки и соответствует стилю страницы.
