# Spec for Рекламная активность - Топ 5 Общая реклама

figma_component (if used): not used

## Summary
Добавить первый аналитический блок страницы `Рекламная активность`: карточку `ТОП-5 • ОБЩАЯ РЕКЛАМА`, которая показывает пять брендов с наибольшим значением рекламной активности по мере `400_00_12_Nat_Big_switch_left`.

Блок должен визуально соответствовать референсу `screenshots/00_40_screen.jpg`: темная карточка, золотой акцент, светлый основной текст, приглушенные подписи и горизонтальные бары.

## Functional Requirements

### Data Sources
- Бренды: таблица `brand_main_Top`, поле `brand_main_top`.
- Логотипы: таблица `logos_dict`, поле `logo_link`.
- Связь логотипов с брендами уже есть в модели:
  - `logos_dict[brand_name]` -> `brand_main_Top[brand_main_top]`.
- Значение для ранжирования и отображения: мера `400_00_12_Nat_Big_switch_left`.
- Блок должен учитывать текущий filter context страницы:
  - фильтр дат;
  - фильтр брендов;
  - будущие фильтры страницы, если они появятся.

### Ranking Logic
- Показывать только Top 5 брендов по убыванию меры `400_00_12_Nat_Big_switch_left`.
- Исключать строки, где значение меры blank или 0.
- Исключать техническую строку `ОСТАЛЬНОЕ`, если она попадает в `brand_main_Top[brand_main_top]`.
- Если выбранных брендов меньше пяти, показывать доступное количество строк.
- Сортировка:
  - основной ключ: `400_00_12_Nat_Big_switch_left` по убыванию;
  - при равенстве значений: `brand_main_Top[brand_main_top]` по возрастанию.

### Displayed Fields
- Номер позиции: `1` - `5`.
- Логотип бренда:
  - source: `logos_dict[logo_link]`;
  - отображать как image URL;
  - размер логотипа в строке: примерно `32 x 32`;
  - скругление по возможности, как в референсе.
- Название бренда:
  - source: `brand_main_Top[brand_main_top]`;
  - отображать справа от логотипа.
- Значение:
  - source: `400_00_12_Nat_Big_switch_left`;
  - формат отображения: целое число `#,0`;
  - после значения всегда отображать подпись `TRP`.
- Доля/SOV:
  - source: мера `3102_01_SOV_%`;
  - отображать справа от горизонтального бара;
  - формат: `0% SOV`;
  - если значение blank, показывать пустую строку без заглушки;
  - стиль как в референсе: приглушенный серый текст, обычный вес, выравнивание вправо.
- Горизонтальный бар:
  - длина пропорциональна значению строки относительно максимального значения среди Top 5;
  - цвет бара: золотой `#E2C16F`;
  - фон бара: `#1C2739`.

### Layout
- Блок размещается под верхней панелью фильтров.
- Фактические координаты после правок в Power BI для страницы `1500 x 1100`:
  - `x=31.94`;
  - `y=262.81`;
  - `w=714.37`;
  - `h=230.86`.
- Карточка должна иметь внутренние отступы и не перекрывать верхние фильтры.
- Заголовок блока:
  - текст: `ТОП-5 • ОБЩАЯ РЕКЛАМА`;
  - расположен в верхней части карточки;
  - слева допускается иконка/символ кубка, если это можно сделать средствами Power BI без нарушения стиля.
- Строки Top 5:
  - равная высота строк;
  - порядок сверху вниз от 1 до 5;
  - логотипы и названия выровнены по одной вертикали;
  - числовые значения выровнены вправо перед баром или рядом с баром;
  - SOV выровнен вправо справа от бара.

### Visual Style
- Фон страницы уже задан в общей спецификации: `#0A0E19`.
- Фон карточки: `#0F1722`.
- Рамка карточки: `#1C2739`.
- Заголовочный акцент: `#E2C16F`.
- Основной текст: `#E3EAF2`.
- Вторичный текст и номера строк: `#9AA3B2`.
- Бар значения:
  - fill: `#E2C16F`;
  - track: `#1C2739`.
- Visual header должен быть выключен.
- Фон внутренних визуалов должен быть прозрачным или совпадать с фоном карточки.

### Recommended Implementation
- Предпочтительно реализовать блок как один кастомный HTML visual, если текущий отчет поддерживает `htmlContent443BE3AD55E043BF878BED274D3A6855`.
- Альтернатива: набор стандартных Power BI visuals внутри фоновой карточки:
  - shape/card background;
  - table/matrix с image URL;
  - bar chart или data bars.
- Для стабильного визуального результата предпочтителен единый HTML visual, потому что стандартная таблица хуже контролирует скругления логотипов, бары и spacing.

### Supporting Measures
- Если HTML visual требует одну HTML-строку, использовать отдельную меру:
  - `_Меры_30_Presentation[3202_01_html_top5_general_ads]`.
- Мера должна строить Top 5 через `TOPN` по `brand_main_Top[brand_main_top]` и мере `400_00_12_Nat_Big_switch_left`.
- HTML должен использовать `logos_dict[logo_link]` для `<img src=...>`.
- HTML должен экранировать/обрабатывать пустые logo URL.

## Possible Edge Cases
- У бренда нет логотипа в `logos_dict`: показывать текстовую заглушку с первой буквой бренда или пустой квадрат в цвете `#1C2739`.
- Значение меры blank или 0: бренд не попадает в Top 5.
- В фильтре брендов выбрано меньше пяти брендов: блок показывает меньше пяти строк без пустых строк.
- В выбранном периоде нет данных: показывать пустое состояние `Нет данных` в теле карточки.
- Очень длинное название бренда: обрезать с ellipsis, не переносить на вторую строку.
- Ошибка/недоступность URL логотипа: строка должна оставаться читаемой.

## Acceptance Criteria
- На странице есть блок `ТОП-5 • ОБЩАЯ РЕКЛАМА`.
- Блок расположен под фильтрами и не перекрывает заголовок, фильтры и индикатор дат.
- Блок показывает не более пяти брендов.
- Бренды отсортированы по `400_00_12_Nat_Big_switch_left` по убыванию.
- В строках отображаются номер позиции, логотип, название бренда, значение и горизонтальный бар.
- SOV/доля отображается справа от горизонтального бара.
- Логотипы берутся из `logos_dict[logo_link]`.
- Названия брендов берутся из `brand_main_Top[brand_main_top]`.
- Значения берутся из меры `400_00_12_Nat_Big_switch_left` и отображаются в целых числах с подписью `TRP`.
- Блок реагирует на фильтр дат и фильтр брендов.
- Цвета и общий стиль соответствуют референсу `screenshots/00_40_screen.jpg`.

## Decisions
- SOV отображаем справа от бара по мере `3102_01_SOV_%`.
- Единица отображения для значения: фиксированная подпись `TRP`, формат числа `#,0`.
