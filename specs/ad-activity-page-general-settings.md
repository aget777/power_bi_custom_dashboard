# Spec for Рекламная активность - общие настройки страницы

figma_component (if used): not used

## Summary
Подготовить базовый каркас страницы Power BI "Рекламная активность": общий фон, фильтр по датам, заголовок страницы и текстовый индикатор выбранного диапазона дат в правом верхнем углу.

Спецификация описывает первый слой страницы без детализации последующих графиков и таблиц.

## Functional Requirements

### Page
- Display name страницы: `Рекламная активность`.
- Базовый размер страницы: использовать текущий формат рабочей страницы `1500 x 1100`.
- Display option: `FitToPage`, чтобы страница корректно открывалась на разных экранах.
- Все элементы верхней панели должны находиться в первом экране и не перекрываться с будущими визуализациями.

### Background
- Фон страницы: темный цвет из референса `screenshots/00_40_screen.jpg`, базовый HEX `#0A0E19`.
- Фон должен занимать всю страницу.
- У декоративных контейнеров и будущих визуализаций не должно быть случайных контрастных подложек, если это не требуется отдельной спецификацией.
- Отдельный брендовый фон или брендовая палитра для этого этапа не используются.
- Базовые цвета из референса:
  - фон страницы: `#0A0E19`;
  - фон контролов/панелей: `#0F1722`;
  - границы и разделители: `#1C2739`;
  - заголовочный акцент: `#E2C16F`;
  - основной светлый текст: `#E3EAF2`;
  - вторичный текст: `#9AA3B2`.

### Page Title
- Заголовок: `Рекламная активность`.
- Расположение: левый верхний угол.
- Фактические координаты после правок в Power BI для `1500 x 1100`: `x=32`, `y=24`, `w=560`, `h=36`.
- Стиль:
  - font family: `Segoe UI`;
  - font size: `24`;
  - font weight: semibold;
  - color: `#E2C16F`;
  - background: transparent;
  - border: off.

### Date Filter
- Источник данных: существующая таблица календаря, поле `'Календарь'[Дата]`.
- Тип визуала: slicer.
- Режим выбора: date range / between.
- Рекомендуемое расположение: под заголовком в левой части страницы.
- Фактические координаты после правок в Power BI для `1500 x 1100`: `x=31.94`, `y=148.10`, `w=341.21`, `h=56.63`.
- Заголовок фильтра: `Период`.
- Срез должен фильтровать все визуализации страницы, которые зависят от календаря.
- Срез не должен использовать жестко заданные даты; доступный диапазон берется из модели.
- Дефолтный выбранный период: с `27.04.2026` по `03.05.2026`.
- Дефолтное состояние должно быть сохранено явно: через состояние slicer/bookmark или эквивалентную настройку PBIP-страницы.
- Календарь на этой странице не нужно ограничивать по максимальной дате Adex через меру `2901_01_05_adex_calendar_filter`.

### Selected Date Range In Top Right
- В правом верхнем углу должен отображаться фактически выбранный диапазон дат.
- Источник значения: DAX measure, использующая существующие меры минимальной и максимальной выбранной даты в текущем filter context.
- Рекомендуемое имя меры: `2901_01_06_текст_выбранный_диапазон`.
- Рекомендуемая папка меры: `_Меры_29_Текст_и_Даты / 29_01_01_Даты`.
- Для расчета нужно переиспользовать существующие меры:
  - `2901_01_01_Мин_текущая_дата` - минимальная выбранная дата в календаре;
  - `2901_01_02_Макс_дата_календарь` - максимальная выбранная дата в календаре.
- Рекомендуемый DAX:

```DAX
2901_01_06_текст_выбранный_диапазон =
VAR MinDate = [2901_01_01_Мин_текущая_дата]
VAR MaxDate = [2901_01_02_Макс_дата_календарь]
RETURN
    IF(
        ISBLANK(MinDate) || ISBLANK(MaxDate),
        "Период не выбран",
        IF(
            MinDate = MaxDate,
            FORMAT(MinDate, "dd.MM.yyyy"),
            FORMAT(MinDate, "dd.MM.yyyy") & " - " & FORMAT(MaxDate, "dd.MM.yyyy")
        )
    )
```

- Тип визуала: card или text visual с привязкой к мере.
- Фактические координаты после правок в Power BI для `1500 x 1100`: `x=920`, `y=24`, `w=328`, `h=32`.
- Стиль:
  - text align: right;
  - font family: `Segoe UI`;
  - font size: `13`;
  - color: `#9AA3B2`;
  - background: transparent;
  - category label: off;
  - visual header: off;
  - border: off.

## Possible Edge Cases
- Не выбран ни один день: показывать `Период не выбран`.
- Выбран один день: показывать одну дату без повторения диапазона.
- Выбран весь доступный период: показывать min/max по текущему календарному контексту, без подстановки жестко заданных дат.
- На странице появятся дополнительные фильтры: правый верхний диапазон должен отражать итоговый текущий контекст дат.
- При длинном диапазоне текст должен оставаться в одну строку и не перекрывать заголовок.

## Acceptance Criteria
- В отчете есть страница с названием `Рекламная активность`.
- Страница имеет единый нейтральный фон без видимых артефактов.
- В левом верхнем углу отображается заголовок `Рекламная активность`.
- На странице есть фильтр по `'Календарь'[Дата]` в режиме диапазона.
- При первом открытии страницы выбран период `27.04.2026 - 03.05.2026`.
- В правом верхнем углу отображается выбранный диапазон дат в формате `dd.MM.yyyy - dd.MM.yyyy`.
- При изменении фильтра по датам текст диапазона обновляется.
- Текст диапазона рассчитывается мерой, а не задан статически в визуале.
- На странице не применено ограничение календаря по максимальной дате Adex.
- Элементы верхней панели не перекрываются на размере страницы `1500 x 1100`.

## Decisions
- Дефолтный выбранный период: `27.04.2026 - 03.05.2026`.
- Ограничение календаря по максимальной дате Adex: не используется.
- Отдельный брендовый фон/цвета: не используются.
