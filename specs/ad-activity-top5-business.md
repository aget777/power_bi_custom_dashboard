# Spec for Рекламная активность - Топ 5 Бизнес

figma_component (if used): not used

## Summary
Добавить на страницу `Рекламная активность` правый аналитический блок `ТОП • БИЗНЕС`: таблицу брендов по бизнес-рекламной активности с логотипами, горизонтальными барами, SOV справа от бара и нижним блоком `БИЗНЕС-СЕГМЕНТЫ`.

## Functional Requirements

### Data Sources
- Бренды: `brand_main_Top[brand_main_top]`.
- Логотипы: `logos_dict[logo_link]`.
- Значение для ранжирования, подписи и бара: мера `3132_01_TPR_Бизнес`.
- Значение в строках отображается в целых числах с фиксированной подписью `TRP`.
- Процент в заголовке в скобках: мера `3132_02_SOV_%_Бизнес`, формат `0% АКТИВНОСТИ`.
- Значение `% SOV` в строках справа от бара: мера `3121_02_SOV_%_category_5_n_6`, формат `0% SOV`.
- Блок `БИЗНЕС-СЕГМЕНТЫ`:
  - `Бухгалтерия`: `3133_02_SOV_%_Бизнес_Бухгалтерия`;
  - `Платежи и переводы`: `3134_02_SOV_%_Бизнес_Платежи_и_переводы`;
  - `Кредиты`: `3135_02_SOV_%_Бизнес_Кредиты`.

### Ranking Logic
- Показывать не более пяти брендов.
- Исключать строки, где `3132_01_TPR_Бизнес` blank или меньше `1`.
- Исключать `ОСТАЛЬНОЕ`.
- Сортировать по `3132_01_TPR_Бизнес` по убыванию, при равенстве по названию бренда по возрастанию.
- Учитывать текущий filter context страницы через `ALLSELECTED('brand_main_Top'[brand_main_top])`.
- Дополнительные фильтры будут накладываться на visual вручную в Power BI.

### Layout
- Реализация: единый HTML visual.
- HTML-мера: `_Меры_30_Presentation[3202_03_html_top5_business]`.
- Visual container: `aa100000000000000009`.
- Позиция на странице `5752fcd0093969ea3e03`:
  - `x=782.4900766593191`;
  - `y=551.4058290472692`;
  - `w=715.1604212588783`;
  - `h=305.0`.

### Visual Style
- Стиль аналогичен таблице `ТОП-5 • РОЗНИЦА`.
- Акцент бизнес-блока: золотой `#E2C16F`.
- Цвета бизнес-сегментов:
  - `Бухгалтерия`: `#5DB9F1`;
  - `Платежи и переводы`: `#F2A35E`;
  - `Кредиты`: `#63D7BE`.
- Каждый сегмент имеет цветную рамку, вертикальный маркер слева, название слева и процент справа.
- Фон карточки: `#0F1722`.
- Рамка: `#1C2739`.
- Основной текст: `#E3EAF2`.
- Вторичный текст: `#9AA3B2`.
- Visual header, background и border контейнера выключены.

## Acceptance Criteria
- На странице есть блок `ТОП • БИЗНЕС`.
- В заголовке отображается процент из `3132_02_SOV_%_Бизнес` в скобках со словом `АКТИВНОСТИ`.
- Таблица показывает бренды с логотипом, названием, значением, баром и `% SOV`.
- Строки с blank или значением `3132_01_TPR_Бизнес < 1` не выводятся.
- Значение и ширина бара рассчитываются по `3132_01_TPR_Бизнес`.
- Значение отображается в формате `#,0 TRP`.
- `% SOV` справа от бара рассчитывается по `3121_02_SOV_%_category_5_n_6`.
- Нижний блок `БИЗНЕС-СЕГМЕНТЫ` показывает три значения из мер `3133_02`, `3134_02`, `3135_02`.
- Визуал не перекрывает существующие блоки и соответствует стилю страницы.
