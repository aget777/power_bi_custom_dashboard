# Spec for Рекламная активность - Завершились кампании

figma_component (if used): not used

## Summary
Добавить на страницу `Рекламная активность` блок `ЗАВЕРШИЛИСЬ КАМПАНИИ`, визуально соответствующий референсу `screenshots/00_40_screen.jpg`: темная карточка, красный акцент, бейдж статуса `STOP` и списки кампаний в колонках `Розница` и `Бизнес`.

## Functional Requirements

### Data Sources
- Статус кампании: мера `_Меры_30_Presentation[3110_02_Stop_campaigns]`.
- Название кампании: таблица `campaigns_dict`, поле `campaign_name`.
- Категория кампании: таблица `campaigns_dict`, поле `campaign_category`.
- Блок должен учитывать текущий filter context страницы, включая фильтр дат и page-level фильтры.

### Displayed Fields
- Статус:
  - source: `3110_02_Stop_campaigns`;
  - отображать слева в строке как красный бейдж;
  - ожидаемое значение: `STOP`.
- Название кампании:
  - source: `campaigns_dict[campaign_name]`;
  - отображать справа от бейджа;
  - длинные названия обрезать через ellipsis.
- Категория кампании:
  - source: `campaigns_dict[campaign_category]`;
  - определяет колонку отображения;
  - `РОЗНИЦА` отображается в колонке `Розница`;
  - `БИЗНЕС` отображается в колонке `Бизнес`.

### Layout
- Блок размещается под карточкой `НОВЫЕ КАМПАНИИ` на странице `5752fcd0093969ea3e03`.
- Фактические координаты для страницы `1500 x 1100`:
  - `x=31.35`;
  - `y=765`;
  - `w=715.16`;
  - `h=300`.

### Visual Style
- Фон карточки: `#0F1722`.
- Рамка карточки: `#1C2739`.
- Заголовок: `ЗАВЕРШИЛИСЬ КАМПАНИИ`, светлый текст `#E3EAF2`, uppercase, увеличенный letter spacing.
- Иконка слева от заголовка: красный `×`, цвет `#FF6B78`.
- Бейдж статуса: красный фон `#6D3435`, светло-красный текст `#FF8D91`.
- Название кампании: светлый текст `#E3EAF2`.

## Acceptance Criteria
- На странице есть блок `ЗАВЕРШИЛИСЬ КАМПАНИИ`.
- Блок показывает кампании, у которых мера `3110_02_Stop_campaigns` возвращает непустой статус.
- В каждой строке слева отображается статус из `3110_02_Stop_campaigns`, справа название из `campaigns_dict[campaign_name]`.
- Кампании разбиты на колонки по `campaigns_dict[campaign_category]`: `Розница` и `Бизнес`.
- Если в категории нет завершившихся кампаний, отображается `Нет кампаний`.
- Блок визуально соответствует референсу по темной карточке, красному акценту и бейджу `STOP`.
