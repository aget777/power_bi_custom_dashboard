# Spec for Рекламная активность - Новые кампании

figma_component (if used): not used

## Summary
Добавить на страницу `Рекламная активность` блок `НОВЫЕ КАМПАНИИ`, визуально соответствующий референсу `screenshots/00_40_screen.jpg`: темная карточка, зеленый акцент, бейдж статуса `NEW` и название кампании.

## Functional Requirements

### Data Sources
- Статус кампании: мера `_Меры_30_Presentation[3110_01_New_campaigns]`.
- Название кампании: таблица `campaigns_dict`, поле `campaign_name`.
- Категория кампании: таблица `campaigns_dict`, поле `campaign_category`.
- Блок должен учитывать текущий filter context страницы, включая фильтр дат и page-level фильтры.

### Displayed Fields
- Статус:
  - source: `3110_01_New_campaigns`;
  - отображать слева в строке как зеленый бейдж;
  - ожидаемое значение: `NEW`.
- Название кампании:
  - source: `campaigns_dict[campaign_name]`;
  - отображать справа от бейджа;
  - длинные названия обрезать через ellipsis.
- Категория кампании:
  - source: `campaigns_dict[campaign_category]`;
  - в текущем HTML-блоке не выводится отдельным текстом;
  - используется для стабильной сортировки строк перед названием кампании.

### Layout
- Блок размещается под карточкой `ТОП-5 • ОБЩАЯ РЕКЛАМА` на странице `5752fcd0093969ea3e03`.
- Фактические координаты для страницы `1500 x 1100`:
  - `x=31.35`;
  - `y=489.84`;
  - `w=715.16`;
  - `h=250.80`.

### Visual Style
- Фон карточки: `#0F1722`.
- Рамка карточки: `#1C2739`.
- Заголовок: `НОВЫЕ КАМПАНИИ`, светлый текст `#E3EAF2`, uppercase, увеличенный letter spacing.
- Иконка слева от заголовка: зеленый `!`, цвет `#63D77A`.
- Бейдж статуса: зеленый фон `#2D6A3A`, светло-зеленый текст `#9DEB9F`.
- Название кампании: светлый текст `#E3EAF2`.

## Acceptance Criteria
- На странице есть блок `НОВЫЕ КАМПАНИИ`.
- Блок показывает кампании, у которых мера `3110_01_New_campaigns` возвращает непустой статус.
- В каждой строке слева отображается статус из `3110_01_New_campaigns`, справа название из `campaigns_dict[campaign_name]`.
- Строки отсортированы по `campaigns_dict[campaign_category]`, затем по `campaigns_dict[campaign_name]`.
- Если новых кампаний нет, отображается пустое состояние `Нет новых кампаний`.
- Блок визуально соответствует референсу по темной карточке, зеленому акценту и бейджу `NEW`.
